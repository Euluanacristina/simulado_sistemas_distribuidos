# Simulado de Sistemas Distribuídos

Site estático em HTML, CSS e JavaScript para estudar Sistemas Distribuídos.

## Materiais usados

- `Sistema_distribuidos_COMPLETO_25_questoes.pdf`
- `Atividade 230926 SD.pdf`

## Funcionalidades

- Simulado de prova com 10, 20 ou 30 questões.
- Treino com correção imediata.
- Treino por assunto.
- Refazer erros.
- Revisão rápida.
- Histórico e progresso local com `localStorage`.
- Modo claro e escuro.
